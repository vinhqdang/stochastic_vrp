# BATON — manuscript directory

Computers & Operations Research, manuscript CAOR-D-26-01885 (see
`STATUS.md` for the review state).

## Files

| File | Content |
|---|---|
| `main.tex` / `main.pdf` | manuscript (elsarticle, author-year) |
| `tables/*.tex` | every results table and `macros.tex` (inline numbers), generated by `make_tables.py` — never edit by hand |
| `figures/*.png` | figures, generated by `svrpspd_wdro/scripts/make_figures.py` (fig1, fig2a/b, fig3, fig4, fig5, fig7, fig8) and `animate_execution.py` (fig6) |
| `BatonProofs/` | Lean 4 + Mathlib machine-checked proofs of Propositions 1–4 (`lake build`; see its README for the theorem-by-theorem correspondence) |
| `references.bib`, `VERIFY_CITATIONS.md` | bibliography and its verification log |
| `title_page`, `cover_letter`, `declaration_of_interests`, `credit_author_statement`, `highlights.txt` | submission set |
| `r1/response_letter.tex` / `.pdf` | point-by-point response to the reviews (revision 1) (cross-references and numbers come from `../main.aux` and `../tables/macros.tex`) |
| `r1/portal_replies.md` | one reply per reviewer, to paste into the Elsevier portal |
| `r1/main_diff.pdf` | revision 1 with changes marked against the submitted version |

## Regenerating

From `svrpspd_wdro/` (plans are cached in `results/plans*/`, so no ALNS
run is needed):

```bash
# main evaluations (all tables of Section 4.2-4.3, 4.8)
python scripts/run_realistic_eval.py policies=Det,SAA,WDRO,Gounaris,Cui,MDRO out=results_grand_dethloff
python scripts/run_realistic_eval.py dir=data/SalhiNagy policies=Det out=results_salhinagy_eval
python scripts/run_realistic_eval.py dir=data/City policies=Det out=results_city_eval
python scripts/run_realistic_eval.py dir=data/CityUniform policies=Det out=results_cityuniform_eval
python scripts/make_zero_pickup_variants.py
python scripts/run_realistic_eval.py dir=data/CityZP25 policies=Det out=results_cityzp25_eval
python scripts/run_realistic_eval.py dir=data/CityZP50 policies=Det out=results_cityzp50_eval
python scripts/run_realistic_eval.py dir=data/City policies=SAA out=results_city_saa_eval
bash scripts/run_cost_sensitivity.sh
python scripts/run_realistic_eval.py policies=Det,SAA max=12 costs=F_standby:60 out=results_costsens_F_standby_60
for x in 5 10 20 30; do
  python scripts/run_realistic_eval.py policies=Det,SAA max=12 costs=F_return:$x out=results_costsens_F_return_$x
done

# revision experiments (Sections 4.4-4.7 and the appendix): results/r1/*.csv
for m in synthetic regret fresh shape dependence exact daytype budget pool; do
  python scripts/run_baton_r1.py $m
done
python scripts/run_baton_r1.py timing workers=1

# RL baseline (CPU or GPU)
python scripts/rl_exec_prep.py
cd results && python ../scripts/rl_exec_train.py bundle=rl_bundle.npz epochs=40 seed=0 out=rl_results.json
for s in 0 1 2; do python ../scripts/rl_exec_train.py bundle=rl_bundle.npz epochs=150 seed=$s out=rl_strong_s$s.json; done

# figures, then tables
python scripts/make_figures.py all
cd ../papers/baton && python make_tables.py
pdflatex main && bibtex main && pdflatex main && pdflatex main
```

Scenario seeds are fixed functions of the instance name, so every run
draws identical demand scenarios. Route-level results for every policy,
gate and instance are written to `svrpspd_wdro/results/routes/`.
