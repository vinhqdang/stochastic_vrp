# TRANSVRP — transformers and LLMs for stochastic VRP

Study folder for a new paper on transformer / LLM methods for stochastic
vehicle routing (SVRPSPD, shared engine in `svrpspd_wdro/`).

| file | content |
|---|---|
| `STATUS.md` | venue, state, freeze and separation policy, blockers |
| `PROJECT.md` | seed-paper analysis, literature map, candidate directions, go/no-go tests |
| `references.bib` | 13 arXiv-verified entries (no venue claims) |
| `VERIFY_CITATIONS.md` | what was verified, what was not |
| `code/` | self-contained code: copied BATON baseline, Dethloff data and plans, parity test (see `code/README.md`) |
| `refs_local/` | local copy of the seed paper (arXiv 2609.01933v2) |

No tables or figures exist yet. When they do, each must regenerate from a
script in this directory or in `svrpspd_wdro/neural/`, and this README
records the command.
