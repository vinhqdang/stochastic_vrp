# ECLAIR implementation (self-contained — no `svrpspd_wdro/` imports)

Phase-2 prototype: the full certification pipeline on real CPMpy +
OR-Tools CP-SAT models, in two experiments —

1. **Mutation testbed** (`run_experiment.py`): candidates are the
   reference model or *functionally corrupted* variants (misread
   bounds, misaligned data columns, dropped constraint rows/families,
   flipped comparison operators — the systematic error classes of LLM
   modellers), so ground truth is known exactly and the statistical
   claims (validity vs alpha, detection, routing gains, e-BH FDR) are
   measurable.
2. **End-to-end LLM experiment** (`run_llm_experiment.py`): candidates
   are generated by real LLMs from natural-language specs via
   OpenRouter, diversified over model family x prompt style x
   temperature, then certified by the same probes with the same
   calibrated bets.

## Setup

```
python3 -m venv ../../../.venv          # or any venv
.venv/bin/pip install cpmpy pytest     # cpmpy pulls OR-Tools
```

LLM experiment additionally needs an OpenRouter key in
`$OPENROUTER_API_KEY` or `./.openrouter_key` (that file is gitignored
— NEVER commit a key). Models: `openrouter/free` and
`nvidia/nemotron-3-ultra-550b-a55b:free`, with `qwen/qwen3.7-flash` as
automatic fallback when the free models' daily quota is exhausted.
Responses are cached in `results/llm_cache.json`, so reruns make no
API calls and are deterministic.

## Layout

- `eclair/problems.py` — 5 problem families (knapsack+conflicts,
  set cover, graph coloring, generalized assignment, on-time job
  selection), each with a reference CPMpy builder, an INDEPENDENT
  pure-Python spec checker (the Tier-A oracle), micro/mid instance
  generators, and the family's provably valid metamorphic relations.
- `eclair/mutations.py` — instance-generic corruption operators +
  semantic screening (equivalent mutants resampled).
- `eclair/probes.py` — Tier A (brute-force micro oracle), Tier B
  (MR check, zero false alarms by proof — asserted in calibration),
  Tier C (partner-majority cross-check, pool-entangled, calibrated
  conservatively). Costs are measured wall-clock solver-seconds.
- `eclair/certify.py` — per-candidate e-processes, conservative
  Bernoulli bets, hard certificates, Kelly/GROW routing (+ round-robin
  and cost-blind ablations), Ville-threshold rejection, e-BH.
- `eclair/calibrate.py` — held-out calibration corpus; Clopper–Pearson
  UPPER bounds for null alarm rates (validity needs only
  p0_true <= p0_bar). Calibration families (knapsack, coloring) are
  DISJOINT from evaluation families (set cover, assignment,
  scheduling), so results also test cross-family transfer.
- `eclair/llm.py` — OpenRouter generation, prompt styles, code
  extraction/exec, intake gate, proxy faithfulness labels.
- `tests/` — 7 pytest tests (oracle agreement, MR validity, mutant
  non-equivalence, supermartingale property of conservative bets,
  Clopper–Pearson correctness, e-BH, end-to-end separation).
  Run: `../../../.venv/bin/python -m pytest tests -q`

## Reproduce

```
cd papers/eclair/code
../../../.venv/bin/python run_experiment.py 100      # calibration + mutation testbed
../../../.venv/bin/python run_llm_experiment.py      # needs API key (or warm cache)
```

Outputs land in `results/` (json + txt committed, run logs stay
local). `results/llm_cache.json` (the raw LLM responses) IS committed:
it makes the LLM experiment exactly reproducible without an API key —
reruns replay the cached generations deterministically.
